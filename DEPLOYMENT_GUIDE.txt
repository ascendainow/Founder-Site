NETLIFY FORMS & FUNCTIONS - DEPLOYMENT GUIDE
=============================================

PRODUCTION-READY CODE PACKAGE
All files needed to deploy the Founder Bottleneck Diagnostic funnel on Netlify

FILES INCLUDED:
===============

FORMS (HTML):
- src-index.html          → Stage 1 Indicator Form (7 questions + contact info)
- src-stage2.html         → Stage 2 Diagnostic Form (12 questions, paid)
- src-results.html        → Dynamic Results Pages (Green/Yellow/Red)
- src-thankyou.html       → Thank You Page with Calendly embed
- src-styles.css          → Stylesheet for all pages

FUNCTIONS (Node.js):
- functions-scoring-logic.js      → Calculate score (Green/Yellow/Red)
- functions-hubspot-sync.js       → Create/update HubSpot contact
- functions-fetch-user-result.js  → Retrieve user score from HubSpot

CONFIG:
- netlify.toml            → Netlify build configuration
- package.json            → Dependencies

QUICK START (5 STEPS)
====================

Step 1: Create GitHub Repository
  1. Create new repo: "founder-diagnostic"
  2. Clone to your machine
  3. Create folder structure:
     founder-diagnostic/
     ├── src/
     ├── functions/
     └── (other config files in root)

Step 2: Add Files to Repository
  src/ folder:
    - index.html (rename from src-index.html)
    - stage2.html (rename from src-stage2.html)
    - results.html (rename from src-results.html)
    - thankyou.html (rename from src-thankyou.html)
    - styles.css (rename from src-styles.css)

  functions/ folder:
    - scoring-logic.js (rename from functions-scoring-logic.js)
    - hubspot-sync.js (rename from functions-hubspot-sync.js)
    - fetch-user-result.js (rename from functions-fetch-user-result.js)

  Root folder:
    - netlify.toml
    - package.json
    - .gitignore (add: node_modules/)

Step 3: Get HubSpot Credentials
  1. Log into HubSpot
  2. Go to Settings > Integrations > Private apps
  3. Create new private app: "Founder Diagnostic"
  4. Add scopes: crm.objects.contacts.read, crm.objects.contacts.write
  5. Generate token and copy it
  6. Find your Portal ID: Settings > Account > Portal ID

Step 4: Deploy to Netlify
  1. Go to netlify.com
  2. Click "New site from Git"
  3. Connect GitHub and select "founder-diagnostic" repo
  4. Configure build:
     Build command: npm install
     Publish directory: src
     Functions directory: functions
  5. Click "Deploy"
  6. Once deployed, go to Site Settings

Step 5: Add Environment Variables
  In Netlify UI:
    Site Settings → Build & Deploy → Environment Variables
    
  Add two variables:
    Key: HUBSPOT_PRIVATE_APP_TOKEN
    Value: [paste your HubSpot private app token]
    
    Key: HUBSPOT_PORTAL_ID
    Value: [paste your HubSpot portal ID]
  
  5. Trigger redeploy (or push new commit to GitHub)

TROUBLESHOOTING
================

Issue: "Missing HubSpot credentials"
Solution: Verify environment variables are set in Netlify UI and site redeployed

Issue: Contact not created in HubSpot
Solution: Check browser console for error messages, verify API token has correct scopes

Issue: Results page shows "Unable to load results"
Solution: Verify email param in URL matches contact email in HubSpot

Issue: Calendly not loading
Solution: Verify Calendly iframe URL is correct (https://calendly.com/soyini-...)
